# Contributing to hotaru_mqtt

Contributions to `hotaru_mqtt` follow
[Hotaru's contribution guide](https://github.com/Field-of-Dream-Studio/hotaru/blob/master/CONTRIBUTING.md),
including its contributor workflow and code standards. See
[GOVERNANCE.md](./GOVERNANCE.md) for this repository's governed scope and the
applicable policy.

## Current status

- The MQTT 3.1.1 implementation is undergoing an audit and hardening pass.
- MQTT 3.1.1 remains supported and under active development.
- MQTT 5.0 support is under development.
